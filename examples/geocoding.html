--- layout: example.html title: Geocoding Search shortdesc: A custom search control using the Nominatim geocoder. docs: > This example shows a custom search control that uses the Nominatim geocoding service of OpenStreetMap. Click the magnifying glass, type a place name and press Enter. A single result is shown directly, multiple results are listed to choose from with the arrow keys and Enter, or with the mouse. The chosen place is marked with a point and a popup with the address. Closing the popup or clearing the search field removes the marker again. Note that the Nominatim usage policy does not allow auto-complete, so a request is only sent when Enter is pressed. tags: "geocoding, search, nominatim, control, popup, overlay" ---
